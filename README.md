 QA End-to-End: SauceDemo

Projeto de portfólio em **Quality Assurance (QA)** focado na validação completa da aplicação web **SauceDemo**, integrando metodologias ágeis, testes manuais e automação de testes (UI e API).

 Objetivo do Projeto
Demonstrar na prática o ciclo de vida de testes de software (STLC), garantindo a qualidade das entregas desde o levantamento de requisitos e planejamento no Jira até a execução de suítes automatizadas em Java.

---

 Stack Tecnológica e Ferramentas
* **Gestão Ágil e Bug Tracking:** Jira (Kanban / Scrum)
* **Linguagem:** Java
* **Gerenciador de Dependências:** Maven
* **Automação Web (UI):** Selenium WebDriver + JUnit 5
* **Automação e Testes de API:** RestAssured + Postman
* **Versionamento:** Git & GitHub

---

 Estrutura do Repositório (Branches)
O desenvolvimento deste projeto foi dividido por etapas (Sprints) em branches separadas, consolidando as entregas na branch principal (`main`):

* **`sprint-1-manual`**: Plano de testes, cenários em BDD (Gherkin), casos de teste manuais e relatórios de bugs.
* **`sprint-2-automacao-ui`**: Scripts de automação de interface (UI) desenvolvidos com Java, Selenium e JUnit 5.
* **`sprint-3-api`**: Testes automatizados de API utilizando RestAssured e coleções do Postman.
